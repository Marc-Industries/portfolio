# Portfolio · Matteo Marcon

An aerospace-themed high-performance portfolio showcasing the intersection of **Space Systems Engineering**, **Advanced IT Automation**, and **Full-Stack Software Development**.

## 🚀 Overview

This site is designed as a "Mission Control" interface, utilizing a cinematic red/black aesthetic. It documents a multidisciplinary approach to engineering, from the structural qualification of 2U CubeSats to the architecture of multi-tenant MBSE platforms.

### 🛠 Technical Stack

- **Frontend**: Plain HTML5, CSS3 (Custom Properties), Vanilla JavaScript (ES Modules).
- **Visuals**: Three.js (Procedural Planets), FFmpeg (Scrub-ready video pipeline), CSS 3D Transforms.
- **Backend/Tools**: Python, FastAPI, Supabase (PostgreSQL + RLS), Node.js.
- **Aerospace**: ANSYS, SolidWorks, MATLAB, ECSS Standards.

## 🛰 Featured Projects

- **BEPI**: A full-stack MBSE platform for aerospace project integration, managing requirements and budgets under ECSS standards.
- **AlbaSat**: Structural and Thermal Model (STM) qualification and FEM-to-test correlation for a 2U CubeSat mission.
- **AI Automation**: A suite of tools including **Instant Translate** (Gemini 1.5 Flash) and **Spese Smart** (Semantic Finance Parsing).
- **Enterprise Systems**: High-availability data orchestration tools for lead distribution and logistics monitoring.

## 📁 Structure

- `/assets` - Global styles, core runtime logic, and high-fidelity media assets.
- `/projects` - Detailed cinematic case studies for each engineering mission.
- `/cv.html` - A "Personnel Dossier" providing a professional record of experience.

## ⚙️ Installation & Local Development

Since this is a static site, you can run it using any local web server:

```bash
# If you have Python installed:
python -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.
