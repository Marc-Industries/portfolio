AlbaSat — CubeSat Platform

Structural engineering, FEM correlation, vibration test campaign

01
PROBLEM
A 1U-class educational CubeSat developed within the University of Padova / Alta Scuola Politecnica framework. Required structural qualification, FEM analysis, modal correlation against vibration test data, and an ECSS-oriented development flow.
02
ARCHITECTURE
Mechanical CAD model (SolidWorks) → FEM (ANSYS) for modal / static analysis → vibration test campaign → correlation of FE modal parameters vs measured data → system-level documentation aligned with ECSS review gates.
03
TECHNOLOGIES
SolidWorksANSYSFEMECSSMATLAB
04
MY ROLE
Structural & systems contributor — FEM modelling, vibration test correlation, ECSS deliverable support.
05
ENGINEERING CHALLENGES
  • ›FEM correlation: matching simulated modal parameters against measured vibration test data within engineering tolerance.
  • ›ECSS-aligned documentation flow from CAD (SolidWorks) to FE (ANSYS) to test campaign to PDR/CDR deliverables.
  • ›Working inside a student team with limited test resources — every test had to count.
06
SOLUTION
A SolidWorks mechanical model fed into ANSYS for modal analysis, then a vibration test campaign to measure the actual modal parameters. Correlation of FE vs test data informed the STM design and the publication at 4S Symposium 2026.
07
RESULT
STM-level qualification data and a publication at the 4S Symposium 2026 ("Simulations and Vibration Test Results for the AlbaSat STM").
08
LESSONS LEARNED
  • ›Test correlation is the only thing that proves your FEM is right. Build the test plan alongside the model.
  • ›ECSS documentation looks heavy at first but pays off when the review gate comes.
