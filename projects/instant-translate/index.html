Instant-Translate

Lightweight multilingual UI helper

01
PROBLEM
Internal tools kept shipping with copy-pasted translation JSON files. Building a tiny library that swaps strings at runtime based on user locale and a context-aware fallback.
02
ARCHITECTURE
Static key → nested JSON lookup with plural / gender / context variants; zero runtime dependencies; < 2 KB minified.
03
TECHNOLOGIES
JavaScriptTypeScriptVite
04
MY ROLE
Designer and developer.
05
ENGINEERING CHALLENGES
  • ›Building a translation helper with plural / gender / context variants without runtime dependencies.
  • ›Keeping the bundle under 2 KB minified.
06
SOLUTION
A tiny key-lookup library with plural / gender / context variants and zero dependencies. < 2 KB minified.
07
RESULT
Used as a helper across several side projects.
08
LESSONS LEARNED
  • ›Small libraries with zero dependencies are easier to keep correct long-term.
